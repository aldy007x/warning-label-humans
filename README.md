This entry is a single-line safety warning label written as if it were printed on every human being at the factory: it opens with the familiar "WARNING: Contains one human" label form, then lists three instantly recognisable human behaviours — lying about being on the way while still in bed, losing the phone it is already holding, and blaming the Wi-Fi for its own decisions — so the joke lands in one read, with the blame-shifting punch arriving in the last few words.

## Entry

> WARNING: Contains one human. May say 'I'm on my way' from bed, lose the phone it is holding, and blame the Wi-Fi for decisions it made itself.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
